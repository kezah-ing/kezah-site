# Kezah Kayitesi, portfolio site

Astro + GSAP + Keystatic. Content lives in `content/` (edited through `/keystatic`), uploads in `public/uploads/`.

- `npm install` then `npm run dev` for a local copy (editor at `/keystatic`).
- `npm run build` makes the production site.
- See `HOW-TO-PUBLISH.md` (editing) and `SETUP-HOSTING.md` (accounts).
